This table still lists `polity/<id>` for every Korea polity, so the site's lookup path (`docs/<region>/ID_MAP.md`) can resolve those aliases the same way it does for Iran. Rows that would say 'dropped' are omitted; no draft ruler or governance ids were assigned.
