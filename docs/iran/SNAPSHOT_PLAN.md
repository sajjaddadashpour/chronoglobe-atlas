# Iran border snapshots: plan (no geometry in this pass)

No borders were drawn in this pass. This file lists the snapshot years Iran needs, why each is needed, and candidate scholarly map sources per period.
Spacing rule: about every 50-100 years in slow periods, and every 15-25 years (or at each turning point) in fast-changing ones (1335-1405, 1500-1530, 1700-1800).
**"Event year verified"** means the year was checked against a source in this pass (ids are files in `sources/`). Years marked *to verify* are planning anchors only and must be checked before geometry is drawn.

Licensing note: the current shapes are historical-basemaps (GPL, kept in `borders/gpl/`). New CC-BY shapes must be digitised from scratch (or traced from sources whose licence allows it). Shapes must not be traced from copyrighted atlases; atlases are used only as evidence for where a boundary ran, cited per polygon.
